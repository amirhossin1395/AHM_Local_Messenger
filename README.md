## 🎯 چیه؟ | What is it?

**فارسی:** یه پیام‌رسان محلی که روی شبکه داخلی (LAN) کار می‌کنه و نیازی به اینترنت نداره!

**English:** A local messenger that works on LAN — no internet required!

## ✨ امکانات | Features

### 💬 پیام‌رسانی | Messaging
- ✅ چت متنی Real-time | Real-time Text Chat
- ✅ ارسال فایل و تصویر | File & Image Sharing
- ✅ تماس صوتی/تصویری (WebRTC) | Voice/Video Calls
- ✅ تبدیل ویس به متن | Voice-to-Text
- ✅ اعلان‌ها | Notifications

### 🔐 امنیت | Security
- ✅ رمزنگاری پیام‌ها | Message Encryption
- ✅ احراز هویت | User Authentication
- ✅ پروفایل کاربری | User Profile

### 📊 مدیریت | Management
- ✅ داشبورد کاربری | User Dashboard
- ✅ تنظیمات پیشرفته | Advanced Settings
- ✅ جستجوی هوشمند | Smart Search
- ✅ آنالیتیکس | Analytics

### 💾 دیتابیس | Database
- ✅ SQLite + پشتیبان‌گیری | SQLite + Backup
- ✅ فشرده‌سازی | DB Compressor
- ✅ بهینه‌سازی | Auto Optimizer

### 🖼️ بهینه‌سازی | Optimization
- ✅ فشرده‌سازی تصاویر | Image Optimizer
- ✅ مدیریت فایل | File Manager

## 📦 نصب | Installation

**۱. کلون کردن | Clone:**
```bash
git clone https://github.com/amirhossin1395/AHM_Local_Messenger.git
cd AHM_Local_Messenger

```
۲. نصب کتابخانه‌ها | Install Requirements:

```bash
pip install -r requirements.txt

```
۳. اجرای سرور | Run Server:

```bash
python run.py

```
۴. باز کردن مرورگر | Open Browser:

```text
http://localhost:8000

```

🎮 چطوری استفاده کنم؟ | How to Use?

فارسی:

💬 Start chatting!
